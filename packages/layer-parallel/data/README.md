# Contracts of feature 142

Feature 142 has no extension point of its own. The interfaces it implements are contracts of
feature 100 (`specs/100-specstride/annexes/D-pass-loop.md`, §D.1 to §D.3). The files here are the
data this feature owns. Where a file and `spec.md` differ, `spec.md` stands.

| File | Content | Requirements |
|---|---|---|
| `closed-sets.json` | The five closed sets, with the row of annex X §X.6 and the rule for an unknown value | F142-FR-002, F142-FR-010, F142-FR-011, F142-FR-023, F142-FR-058 |
| `loop-fields.json` | The fields this feature adds to the `[LOOP]` line and to the run record | F142-FR-022 |
| `vocabulary.json` | The list of the vocabulary test over critic-class inputs | F142-FR-066 |
| `fx-par.json` | The fixtures of FX-PAR-S and the arms of FX-PAR-L | F142-FR-072 |
